# Hospital Patient, Operations & Billing Analysis

## Python Data Analytics Project

This project focuses on analyzing hospital patient data, operational efficiency, waiting times, patient satisfaction, and billing performance using Python.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- SciPy

## Project Analysis
1. Patient Demographics Analysis
2. Hospital Visit Analysis
3. Waiting Time Analysis
4. Patient Satisfaction Analysis
5. Billing & Insurance Analysis
6. Statistical Analysis

## Project Files

- Jupyter Notebook: Python analysis and visualizations
- Patients Dataset
- Visits Dataset
- Billing Dataset

## Project Objectives
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Statistical Analysis
- Business Insights
